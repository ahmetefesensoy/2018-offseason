# Source and asset provenance

The owner describes this repository as personal experimental code, never used in a competition. The original code is licensed under the root MIT license. Dependencies, their notices and their original licenses remain applicable.

`Assembly 1.step` is pre-existing CAD whose authorship and redistribution license have not been established in this review. It is excluded from the root MIT grant. No downloaded Team 3028 CAD is included. The URDF is a simplified geometric proxy using documented envelope measurements, not a detailed team CAD model.

The optional YOLO runtime uses Ultralytics. Its own license and any model/dataset licenses are separate from this project's source license. No trained weights or cube dataset are bundled. The HSV baseline is original source and needs no trained weights.

Kullanıcı bu kodun kişisel denemesi olduğunu ve yarışmada kullanılmadığını belirtti. STEP dosyasının kaynak/lisans kaydı bilinmiyor; MIT kapsamına alınmadı. YOLO, model ağırlıkları ve veri setleri kendi lisanslarına tabidir.
